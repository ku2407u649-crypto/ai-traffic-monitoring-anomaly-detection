**Project Mentor:** Ms. Pragya Vats

## About
An AI system that analyses road-camera video in real time. It detects and classifies vehicles (YOLO), tracks them across frames, and flags anomalies such as stopped vehicles, wrong-way driving, over-speeding and sudden congestion using a hybrid of rule-based checks and machine learning. Results are shown on a dashboard with alerts and event logs.
